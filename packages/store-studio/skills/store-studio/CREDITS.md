# Credits

Store Studio re-exposes two reference skills with attribution. It does not vendor their generators.

## play-store-screenshots

- Project: https://github.com/mobile-dev-ci/play-store-screenshots
- Author: Kushal Agrawal
- Licence: MIT (`references/play-store-screenshots/LICENSE`)

Adapted ideas: the single discovery question ("top features and the problem each solves"), the copy formulas summarised in `SKILL.md`, the `text-top` / `full-bleed` layout names, the neutral device-mockup proportions, the filename convention (`01-phone-portrait.png`), and the QA checklist. The Play validator's banned-word list and alt-text rule come from the same project's Play policy section. The HTML generator itself is **not** copied.

## app-store-screenshots

- Project: https://github.com/Parth Jadhav/app-store-screenshots
- Author: Parth Jadhav
- Licence: MIT, Copyright (c) 2026 Parth Jadhav (`references/app-store-screenshots/LICENSE`)

Adapted ideas: the "screenshots are advertisements, not documentation" framing, the copy-ideas menu (hero / differentiator / feature / proof / closer), cross-screen devices that can be moved across slice cuts, and the editor-first hand-off. The local clone was re-cloned and its licence confirmed before any content was adapted. The Next.js template and its `html-to-image` export path are **not** copied.
